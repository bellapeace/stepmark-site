Help with StepMark

StepMark keeps the workflow lightweight and local. These checks solve the most common recording and export questions.

Start a recording

Open an ordinary HTTPS webpage, open the StepMark side panel, choose Document or Document + Video, and select Start recording. Chrome internal pages such as chrome:// cannot be captured.

Video recording

StepMark includes Chrome's tab-capture capability at installation, but capture starts only after you choose Document + Video and select Start recording. It records the active browser tab rather than the entire desktop. If video capture is interrupted, the editable document remains available.

New tabs and video segments

The document can continue into a newly opened tab. Video may pause and wait for a user gesture before the destination tab can be captured; follow the toolbar badge and click the extension icon when it shows Resume.

Missing or sensitive content

Edit the generated steps and screenshots before exporting. Move or add focus markers and labels, and add manual privacy mosaics where automatic masking did not detect a sensitive value.

AI polish

AI polish is optional. Save and test a provider configuration first. Requests go directly to that provider, so endpoint access, account limits, browser CORS support, and model compatibility can affect the result.

Report a problem

Send the StepMark version, Chrome version, operating system, recording mode, reproduction steps, and the exact visible error to yhou.bella@gmail.com. Do not include API keys, private screenshots, or exported tutorials unless specifically needed and safe to share.
