EDITABLE BY DEFAULT

Keep the useful parts. Fix the imperfect ones.

Delete and reorder steps, rewrite instructions, move focus markers, add labels, and apply privacy mosaics after recording. Long guides can be copied in smaller batches into the documentation you already maintain.

  • Independent focus markers and labels
  • Post-capture automatic and manual masking
  • Optional AI polish with your own model provider

LOCAL BY DEFAULT

Your workflow is not our dataset.

StepMark has no account system or recording backend. Guides, screenshots, video, settings, and model profiles stay in your current Chrome profile until you remove them.

AI polish is optional. When you run it, data goes directly to the provider and endpoint you configured.

Manual installation

For offline testing or when the Chrome Web Store is unavailable. Manual installations require Chrome Developer mode and do not update automatically.

  1. Download and unzip the package.
  2. Open chrome://extensions and enable Developer mode.
  3. Select Load unpacked, then choose the folder containing manifest.json.
