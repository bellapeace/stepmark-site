使用支持

StepMark 使用帮助

StepMark 保持轻量和本地优先。下面的检查方法覆盖最常见的录制与导出问题。

开始录制

打开普通 HTTPS 网页，打开 StepMark 侧边栏，选择“图文教程”或“图文 + 视频教程”，然后点击“开始录制”。chrome:// 等 Chrome 内部页面无法采集。

视频录制

StepMark 在安装时包含 Chrome 的标签页采集能力，但只有在你选择“图文 + 视频教程”并点击“开始录制”后才会开始采集。它录制当前浏览器标签页，不录制整个桌面。如果视频采集被中断，可编辑的图文文档仍会保留。

新标签页与视频片段

图文文档可以继续记录新打开的标签页。视频可能会暂停并等待一次用户操作后才能采集目标标签页；工具栏标记显示 RES 时，请点击 StepMark 扩展图标继续。

内容缺失或包含敏感信息

导出前请检查并编辑生成的步骤和截图。你可以移动或新增焦点与标签，并在自动打码未识别敏感内容时添加手动隐私马赛克。

AI 润色

AI 润色是可选功能。请先保存模型配置并测试连接。请求会直接发送到你选择的服务商，因此 Endpoint 访问、账户额度、浏览器 CORS 支持和模型兼容性都可能影响结果。

反馈问题

请将 StepMark 版本、Chrome 版本、操作系统、录制模式、复现步骤和完整可见报错发送至 yhou.bella@gmail.com。除非确有必要并确认可以安全分享，请勿附带 API Key、含隐私的截图或导出的教程。
