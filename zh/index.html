前往 Chrome 商店安装
手动下载安装

适用于离线测试或无法访问 Chrome 商店的情况。手动安装需要开启 Chrome 开发者模式，并且不会自动更新。

  1. 下载并解压 ZIP 安装包。
  2. 打开 chrome://extensions，开启“开发者模式”。
  3. 点击“加载未打包的扩展程序”。
  4. 在文件选择窗口中，选择刚解压得到的 StepMark 文件夹。
